# 猪羊弟 · 好友联机原型 0.1

这一版在保留本地单机游戏的同时，增加了**独立的好友联机入口**。联机牌局由 Node.js 服务端负责洗牌、发牌、验证合法出牌、收墩、牌面分、特殊牌型、组队和对局点数；浏览器不能提交别人的手牌或自行决定结果。

## 功能

- 创建 6 位房间码、输入房间码加入房间
- 四人座位、准备状态、房主开始游戏
- 房间聊天
- 52 张牌、每人 13 张、梅花 2 持有者获得首墩领出权但不强制出梅花 2
- 强制跟牌、每墩服务器裁决、实时同步手牌/出牌/收牌区
- 按初始手牌猪羊持有者固定本局队伍
- 按最终牌面分判普通局胜负；满贯优先于全红
- 倒板规则、2 打 2 与 1 打 3 对局点数、个人累计点数和目标点数结束
- 同一浏览器会话可恢复房间；玩家断线时保留座位，断线座位超时可由服务器代打合法低牌
- 本地单机版本仍位于 `public/local.html`

## 本地运行

需要 Node.js 20 或更高版本。

```bash
npm install
npm test
npm start
```

浏览器打开 `http://localhost:3000`，首页可选“本地单机”或“好友联机”。本机多人测试可以用四个独立浏览器配置文件/无痕窗口分别进入；不要在四个窗口里共用同一个 localStorage 会话。

## Render 部署

1. 将整个文件夹内容提交到你自己的 GitHub 仓库。
2. Render → New → Web Service，连接这个仓库。
3. Runtime 选择 Node；Build Command 填 `npm install`；Start Command 填 `npm start`。
4. Health Check Path 填 `/healthz`。仓库也附带 `render.yaml`。
5. 部署后打开 Render 分配的 HTTPS 域名，进入“好友联机”；创建房间并把 6 位房间码发给其他玩家。

## 当前原型的边界

- 房间、玩家和牌局暂存在单个 Node 服务进程的内存里，服务器重启或免费实例休眠/重启会清空房间；本版没有数据库持久化。
- 当前按单实例部署设计，没有 Redis 多实例 Socket.IO adapter。
- 断线恢复依赖当前浏览器的 localStorage 会话 token；清除浏览器数据就无法恢复原身份。
- 这是好友房原型，尚未加入账号系统、举报/封禁、反作弊审计日志或商业化能力。

## 本版验证范围

- `node --check server.js` 与 `node --check game.js` 语法检查通过。
- `npm test` 中 12 项规则与界面契约测试通过；测试命令使用 Node 内置测试工具。
- 通过本地浏览器模拟 Socket.IO 事件检查了入口、大厅、牌桌、13 张手牌显示，以及“选择后按钮出牌”和“双击出牌”两条客户端请求路径。
- **当前交付的是可部署源码，不是已经上线的公共网址。** 本开发环境未能安装完成 Express 与 Socket.IO 依赖，因此尚未完成真实 Socket.IO 多设备端到端联机验证。部署到 Render 时，Render 会根据 `package.json` 运行 `npm install`，届时仍需做一次实际的四设备/四浏览器房间测试。
